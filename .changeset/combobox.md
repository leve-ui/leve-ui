Add Combobox, a text input with a listbox of suggestions (APG Combobox with list autocomplete). Focus stays in the input and the highlighted option is set with `aria-activedescendant`; you filter the items with `bind:inputValue`. `@leve-ui/utils` adds collection helpers (`getCollectionItems`, `getAdjacentItem`, `isItemDisabled`, `getItemTextValue`) and `itemId`.

# Components

All components in leve-ui. Each one is included in `@leve-ui/core` and is also published as its own package, `@leve-ui/<name>`.

Pages for the other components are coming soon. Until then, see them in [Storybook](https://leve-ui-storybook.pages.dev).

| Component | Description |
| --- | --- |
| Accordion | A stack of headings that each show or hide a section of content. |
| Alert | A message that draws attention without interrupting the user. |
| [Avatar](/components/avatar/) | An image that represents a user, with a fallback. |
| Breadcrumb | The path to the current page in the site hierarchy. |
| Checkbox | A control that is checked, unchecked, or mixed. |
| Collapsible | A button that shows or hides a section of content. |
| Field | Connects a label, description and error message to a form control. |
| Fieldset | Groups related form controls under a legend. |
| Label | A label for a form control. |
| Meter | A value within a known range, such as disk usage. |
| Progress | The progress of a task, determinate or indeterminate. |
| Radio Group | A set of options where only one can be selected. |
| Separator | A line that separates content. |
| Switch | A control that turns an option on or off. |
| Tabs | Layered panels of content, one shown at a time. |
| Toggle | A button that is pressed or not pressed. |
| Toggle Group | A set of toggle buttons, single or multiple selection. |

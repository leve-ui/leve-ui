# Pagination

Navigation for moving across pages of content, supporting both button-based state updates and link-based navigation.

Pagination uses a `<nav>` landmark, native `<button>` or `<a>` elements, `aria-current="page"` on the active page, and `aria-hidden="true"` on ellipsis indicators.

## Installation

Install the individual package, or use `@leve-ui/core` to get every component at once:

<Install package="@leve-ui/pagination" />

## Anatomy

```tsx
import { Pagination } from '@leve-ui/pagination'; // or '@leve-ui/core'

<Pagination.Root totalPages={10}>
  <Pagination.List>
    <li>
      <Pagination.PrevTrigger />
    </li>
    <li>
      <Pagination.Item value={1}>1</Pagination.Item>
    </li>
    <li>
      <Pagination.Ellipsis />
    </li>
    <li>
      <Pagination.NextTrigger />
    </li>
  </Pagination.List>
</Pagination.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `Pagination.Root` | `<nav>` | The navigation landmark that manages page state and total pages. |
| `Pagination.List` | `<ul>` | The unordered list of pagination controls. Wrap items, triggers, and ellipses in `<li>`. |
| `Pagination.Item` | `<button>` / `<a>` | A control for a specific page number. Renders `<a>` when `href` is provided, or `<button type="button">` otherwise. |
| `Pagination.PrevTrigger` | `<button>` / `<a>` | Navigates to the previous page. Automatically disabled on the first page. |
| `Pagination.NextTrigger` | `<button>` / `<a>` | Navigates to the next page. Automatically disabled on the last page. |
| `Pagination.Ellipsis` | `<span>` | Decorative indicator for omitted pages, hidden from assistive technologies. |

### Custom Link Component

Pass a router link component such as Qwik City's `<Link>` to `as` on `Pagination.Item`, `Pagination.PrevTrigger`, and `Pagination.NextTrigger` for client-side navigation and prefetching while keeping Pagination's attributes:

```tsx
import { Link } from '@builder.io/qwik-city';
import { Pagination } from '@leve-ui/pagination';

<Pagination.Root totalPages={8}>
  <Pagination.List>
    <li>
      <Pagination.PrevTrigger as={Link} href="/items?page=1">
        Previous
      </Pagination.PrevTrigger>
    </li>
    <li>
      <Pagination.Item as={Link} value={2} href="/items?page=2">
        2
      </Pagination.Item>
    </li>
    <li>
      <Pagination.NextTrigger as={Link} href="/items?page=3">
        Next
      </Pagination.NextTrigger>
    </li>
  </Pagination.List>
</Pagination.Root>
```

A component passed to `as` must spread the props it receives onto a single element, including `id`, `aria-*`, `data-*`, and `on*$` event handlers.

### `getPaginationRange`

Pure helper function that computes the sequence of page numbers and ellipsis items to render:

```ts
import { getPaginationRange } from '@leve-ui/pagination';

const range = getPaginationRange({
  page: 5,
  totalPages: 10,
  siblingCount: 1,
  boundaryCount: 1,
});
```

Returns `Array<{ type: 'page'; value: number } | { type: 'ellipsis'; key: string }>`.

## Accessibility

- `Pagination.Root` renders a `<nav>` landmark with `aria-label="Pagination"` by default. Pass `aria-label` or `aria-labelledby` to customize it.
- The active `Pagination.Item` receives `aria-current="page"`.
- `Pagination.Ellipsis` renders `aria-hidden="true"` so screen readers skip decorative ellipsis indicators.
- Disabled `<button>` controls use the native `disabled` attribute. Disabled `<a>` controls omit `href`, set `aria-disabled="true"` and `tabIndex={-1}`, and prevent click navigation.
- Interactive controls are native `<button>` or `<a>` elements and are navigated with `Tab` / `Shift+Tab` and activated with `Enter` (or `Space` for buttons).

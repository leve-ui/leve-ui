# Slider

An input where the user selects a value or range from within a given range.

Follows the [WAI-ARIA APG Slider pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider/) and [Multi-Thumb Slider pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb/).

<Demo id="slider/default" />

## Installation

Install the individual package, or use `@leve-ui/core` to get every component at once:

<Install package="@leve-ui/slider" />

## Anatomy

```tsx
import { Slider } from '@leve-ui/slider'; // or '@leve-ui/core'

<Slider.Root>
  <Slider.Track>
    <Slider.Range />
    <Slider.Thumb />
  </Slider.Track>
  <Slider.HiddenInput />
</Slider.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `Slider.Root` | `<div>` | Root container holding state, range bounds, and Field integration. |
| `Slider.Track` | `<div>` | Interactive track area that jumps the nearest thumb on pointerdown. |
| `Slider.Range` | `<div>` | Visual range highlight exposing `--leve-slider-range-start` and `--leve-slider-range-size`. |
| `Slider.Thumb` | `<span>` | Draggable, focusable thumb with `role="slider"` and `--leve-slider-thumb-percent`. |
| `Slider.HiddenInput` | `<input>` | Visually hidden number input for native `<form>` submission and reset. |

## Accessibility

- `Slider.Thumb` renders `role="slider"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-orientation`, and optional `aria-disabled`, `aria-readonly`, `aria-invalid`, `aria-labelledby`, and `aria-describedby`.
- In multi-thumb sliders, `aria-valuemin` and `aria-valuemax` dynamically reflect adjacent thumb bounds and `minStepsBetweenThumbs`.

| Key | Action |
| --- | --- |
| `ArrowRight` / `ArrowUp` | Increases value by `step` (`ArrowRight` decreases in RTL) |
| `ArrowLeft` / `ArrowDown` | Decreases value by `step` (`ArrowLeft` increases in RTL) |
| `PageUp` | Increases value by `largeStep` |
| `PageDown` | Decreases value by `largeStep` |
| `Home` | Moves thumb to its minimum allowed value |
| `End` | Moves thumb to its maximum allowed value |

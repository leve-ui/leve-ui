# Steps

Guides users through a multi-step workflow with linear and non-linear navigation.

There is no dedicated WAI-ARIA APG pattern for Steps. Steps uses a semantic ordered list (`<ol>` in `Steps.List` and `<li>` in `Steps.Item`), sets `aria-current="step"` on the active step item, and hides decorative indicators and separators with `aria-hidden="true"`.

## Installation

Install the individual package, or use `@leve-ui/core` to get every component at once:

<Install package="@leve-ui/steps" />

## Anatomy

```tsx
import { Steps } from '@leve-ui/steps'; // or '@leve-ui/core'

<Steps.Root count={3}>
  <Steps.List>
    <Steps.Item index={0}>
      <Steps.Trigger>
        <Steps.Indicator>1</Steps.Indicator>
        <span>Account</span>
      </Steps.Trigger>
      <Steps.Separator />
    </Steps.Item>
  </Steps.List>

  <Steps.Content index={0}>Step content</Steps.Content>

  <Steps.PrevTrigger>Previous</Steps.PrevTrigger>
  <Steps.NextTrigger>Next</Steps.NextTrigger>
</Steps.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `Steps.Root` | `<div>` | Wraps the parts and manages the active step, total count, linear mode, and orientation. |
| `Steps.List` | `<ol>` | Ordered list container for step items. |
| `Steps.Item` | `<li>` | Represents a single step at `index` and sets `aria-current="step"` when active. |
| `Steps.Trigger` | `<button>` | Activates its parent step when clicked. Automatically disabled when blocked by `linear` mode or item `disabled`. |
| `Steps.Indicator` | `<span>` | Decorative visual badge (such as a step number or icon), hidden from assistive technologies. |
| `Steps.Separator` | `<div>` | Decorative connector line inside a step item, hidden from assistive technologies. |
| `Steps.Content` | `<div>` | Content panel for a given `index`. Always rendered, with `hidden` applied when inactive. |
| `Steps.PrevTrigger` | `<button>` | Navigates to the previous step. Automatically disabled on the first step. |
| `Steps.NextTrigger` | `<button>` | Navigates to the next step. Automatically disabled on the last step. |

## Examples

### Linear

Pass `linear` on `Steps.Root` to prevent jumping ahead to upcoming steps via `Steps.Trigger`, while still allowing navigation back to completed steps.

## Accessibility

- `Steps.List` renders a semantic `<ol>` and each `Steps.Item` renders an `<li>`.
- The active `Steps.Item` receives `aria-current="step"`.
- `Steps.Indicator` and `Steps.Separator` render `aria-hidden="true"` so screen readers skip decorative numbers, icons, and connector lines.
- `Steps.Trigger`, `Steps.PrevTrigger`, and `Steps.NextTrigger` are native `<button type="button">` elements using the native `disabled` attribute when inactive or blocked by `linear` mode.

### Keyboard Interactions

| Key | Description |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves focus between enabled step triggers and navigation buttons. |
| `Enter` / `Space` | Activates the focused trigger or navigation button. |

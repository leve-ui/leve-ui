# Tree View

A hierarchical list with expandable branches, selection, and keyboard navigation.

Tree View follows the [Tree View WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/).

<Demo id="tree-view/default" />

## Installation

Install the individual package, or use `@leve-ui/core` to get every component at once:

<Install package="@leve-ui/tree-view" />

## Anatomy

```tsx
import { TreeView } from '@leve-ui/tree-view'; // or '@leve-ui/core'

<TreeView.Root aria-label="Files">
  <TreeView.Item value="src" branch>
    <TreeView.ItemTrigger>
      <TreeView.ItemIndicator />
      src
    </TreeView.ItemTrigger>
    <TreeView.Group>
      <TreeView.Item value="src/index.ts">
        <TreeView.ItemTrigger>index.ts</TreeView.ItemTrigger>
      </TreeView.Item>
    </TreeView.Group>
  </TreeView.Item>
</TreeView.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `TreeView.Root` | `<ul>` | The tree container (`role="tree"`). Holds selection, expansion, and focus state. |
| `TreeView.Item` | `<li>` | A tree node (`role="treeitem"`). Set `branch` when it contains a nested group. |
| `TreeView.ItemTrigger` | `<div>` | Clickable row that focuses the item, selects it, and toggles branch expansion. |
| `TreeView.ItemIndicator` | `<span>` | Decorative indicator (`aria-hidden="true"`) such as an expand chevron or checkmark. |
| `TreeView.Group` | `<ul>` | Nested group of child items (`role="group"`). Hidden while its parent branch is collapsed. |

Set `branch` on any `TreeView.Item` that has a child `TreeView.Group`, so `aria-expanded` is emitted accurately during SSR and omitted on leaf items.

## Examples

### Multiple

Pass `multiple` on `TreeView.Root` to allow selecting multiple items at once and set `aria-multiselectable="true"`.

<Demo id="tree-view/multiple" collapsed />

### Controlled

Use `bind:value` and `bind:expandedValue` to read and update selection and branch expansion from outside.

<Demo id="tree-view/controlled" collapsed />

### Disabled

`disabled` on `TreeView.Item` disables that item (and any items nested inside it), and `disabled` on `TreeView.Root` disables the whole tree. Arrow keys and typeahead skip disabled items.

## Accessibility

Complies with the [Tree View WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/).

- Name the tree with `aria-label` or `aria-labelledby` on `TreeView.Root` (`role="tree"`). When `multiple` is `true`, `aria-multiselectable="true"` is added.
- Each `TreeView.Item` renders `role="treeitem"` with `aria-selected`, `aria-level` (computed from nesting depth or `level`), and roving `tabIndex` (`0` on the active tab stop, `-1` on all other items).
- Branch items (`branch={true}`) output `aria-expanded` (`"true"` or `"false"`). Leaf items omit `aria-expanded`.
- `TreeView.ItemIndicator` has `aria-hidden="true"` so decorative chevrons and checkmarks do not clutter screen reader output or typeahead matching.
- Disabled items set `aria-disabled="true"` and `tabIndex={-1}`, and are skipped by navigation and typeahead.

### Keyboard Interactions

| Key | Description |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves focus into the tree (to the active tab stop) or out of the tree. |
| `ArrowDown` / `ArrowUp` | Moves focus to the next or previous visible enabled item without wrapping. |
| `ArrowRight` | On a closed branch, expands it. On an open branch, moves focus to its first enabled child item. |
| `ArrowLeft` | On an open branch, collapses it. On a closed branch or leaf, moves focus to its parent item. |
| `Home` / `End` | Moves focus to the first or last visible enabled item. |
| `Enter` / `Space` | Selects the focused item (or toggles selection when `multiple` is `true`). |
| `*` | Expands all closed enabled sibling branches at the same level without moving focus. |
| Printable characters | Moves focus to the next visible enabled item whose label starts with the typed characters. |

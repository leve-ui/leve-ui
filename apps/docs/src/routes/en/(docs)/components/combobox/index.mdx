# Combobox

A text input with a list of suggestions to pick from, such as a searchable select.

Combobox follows the [Combobox WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) with list autocomplete.

## Anatomy

```tsx
import { Combobox } from '@leve-ui/combobox'; // or '@leve-ui/core'

<Combobox.Root>
  <Combobox.Label />
  <Combobox.Control>
    <Combobox.Input />
    <Combobox.ClearTrigger />
    <Combobox.Trigger />
  </Combobox.Control>
  <Combobox.HiddenInput />
  <Combobox.Content>
    <Combobox.List>
      <Combobox.Item>
        <Combobox.ItemText />
        <Combobox.ItemIndicator />
      </Combobox.Item>
      <Combobox.Group>
        <Combobox.GroupLabel />
        <Combobox.Item />
      </Combobox.Group>
    </Combobox.List>
    <Combobox.Empty />
  </Combobox.Content>
</Combobox.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `Combobox.Root` | `<div>` | Wraps the parts and holds the value, the text and the open state. |
| `Combobox.Label` | `<label>` | The label of the input, also the name of the listbox. |
| `Combobox.Control` | `<div>` | Wraps the input and the trigger. The listbox is placed below it. |
| `Combobox.Input` | `<input>` | The text input. Focus stays here. |
| `Combobox.ClearTrigger` | `<button>` | Optional. Clears the text and the value. Hidden while there is nothing to clear. |
| `Combobox.Trigger` | `<button>` | Optional. Opens and closes the listbox. Not in the tab order. |
| `Combobox.HiddenInput` | `<input>` | Optional. Submits the selected value with a form. |
| `Combobox.Content` | `<div>` | The popup, a `popover="manual"` element in the top layer. |
| `Combobox.List` | `<div>` | The listbox. |
| `Combobox.Item` | `<div>` | An option. |
| `Combobox.ItemText` | `<span>` | The text put in the input when the option is selected. |
| `Combobox.ItemIndicator` | `<span>` | The check mark of the selected option, hidden otherwise. |
| `Combobox.Group` | `<div>` | A group of options, named by its GroupLabel. |
| `Combobox.GroupLabel` | `<div>` | The name of a group. Not an option. |
| `Combobox.Empty` | `<div>` | The message when nothing matches. You decide when to render it. |

## Filtering

The combobox does not filter: render the items that match the text. `onInputValueChange$` tells you the text and why it changed (`reason`): `'input'` when the user typed, and `'select'`, `'clear'` or `'blur'` otherwise. Filter only on `'input'`, so the listbox shows all the items again when it opens after a selection. You can filter in any way, including with a request to a server.

```tsx
const query = useSignal('');
const items = useComputed$(() =>
  FRUITS.filter((fruit) => fruit.label.toLowerCase().includes(query.value.toLowerCase())),
);

<Combobox.Root
  onInputValueChange$={(text, { reason }) => {
    query.value = reason === 'input' ? text : '';
  }}
>
  {/* ... */}
  {items.value.map((fruit) => <Combobox.Item key={fruit.value} value={fruit.value} />)}
</Combobox.Root>
```

`bind:inputValue` also gives you the text, when you need to set it yourself.

When you set `defaultValue` (or `bind:value`), also set the text of that item with `defaultInputValue` (or `bind:inputValue`): the items are not known when the page is rendered on the server.

Typing does not select. When the input loses focus, its text goes back to the selected item, or the value is cleared when the input is empty.

## Opening

The listbox opens when the user types, presses ArrowDown or ArrowUp, or presses the Trigger. With `openOnClick`, clicking the input opens it too; the demo above uses it.

### Groups and Auto Highlight

## Accessibility

Complies with the [Combobox WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/).

- `Combobox.Input` renders `role="combobox"`, `aria-autocomplete="list"`, `aria-expanded` and `aria-controls`. Focus stays in the input, and `aria-activedescendant` points to the highlighted option.
- `Combobox.List` renders `role="listbox"`, named by the Label. Options render `role="option"` with `aria-selected`; disabled ones render `aria-disabled="true"` and are skipped by the arrow keys.
- `Combobox.Group` renders `role="group"`, named by its GroupLabel. `Combobox.ItemIndicator` is hidden from assistive technologies, since `aria-selected` conveys the state.
- Inside a [Field](/components/field/), the input takes the Field's id, label, description, error message, `invalid`, `disabled` and `required`.
- `Combobox.Trigger` and `Combobox.ClearTrigger` are not in the tab order: from the input, the keyboard opens the listbox with ArrowDown and clears with Escape. Give them an `aria-label` when they show only an icon.

### Keyboard Interactions

| Key | Description |
| --- | --- |
| `ArrowDown` | Opens the listbox and highlights the first option, or highlights the next one. |
| `ArrowUp` | Opens the listbox and highlights the last option, or highlights the previous one. |
| `Alt + ArrowDown` | Opens the listbox without highlighting. |
| `Alt + ArrowUp` | Closes the listbox. |
| `Enter` | Selects the highlighted option, puts its text in the input and closes the listbox. |
| `Escape` | Closes the listbox. When it is closed, clears the input and the value. |
| Characters | Type in the input, which opens the listbox. |

# File Upload

A control for selecting and dropping files with validation and form support.

File Upload uses native `<input type="file">`, `<label>`, and `<button type="button">` semantics for accessible file picking, drag-and-drop, and form submission.

<Demo id="file-upload/default" />

## Installation

Install the individual package, or use `@leve-ui/core` to get every component at once:

<Install package="@leve-ui/file-upload" />

## Anatomy

```tsx
import { FileUpload } from '@leve-ui/file-upload'; // or '@leve-ui/core'

<FileUpload.Root>
  <FileUpload.Label />
  <FileUpload.Dropzone>
    <FileUpload.Trigger />
  </FileUpload.Dropzone>
  <FileUpload.HiddenInput />
  <FileUpload.ItemGroup>
    <FileUpload.Item file={file}>
      <FileUpload.ItemName />
      <FileUpload.ItemSize />
      <FileUpload.ItemDeleteTrigger />
    </FileUpload.Item>
  </FileUpload.ItemGroup>
</FileUpload.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `FileUpload.Root` | `<div>` | Wraps the parts, manages accepted files, and validates selections. |
| `FileUpload.Label` | `<label>` | Labels the hidden file input via `for`. |
| `FileUpload.Dropzone` | `<div>` | Drag-and-drop area that also opens the file picker on click. |
| `FileUpload.Trigger` | `<button>` | Opens the native file picker when clicked or activated via keyboard. |
| `FileUpload.HiddenInput` | `<input type="file">` | Visually hidden native file input synchronized with accepted files. |
| `FileUpload.ItemGroup` | `<ul>` | List container for accepted files. |
| `FileUpload.Item` | `<li>` | Represents a single accepted file entry. |
| `FileUpload.ItemName` | `<span>` | Displays the file name (renders `{file.name}` automatically). |
| `FileUpload.ItemSize` | `<span>` | Displays the formatted file size using `formatFileSize`. |
| `FileUpload.ItemDeleteTrigger` | `<button>` | Removes the enclosing item from the file list. |

## Examples

### Multiple

Pass `multiple` on `FileUpload.Root` to allow selecting and appending multiple files.

<Demo id="file-upload/multiple" collapsed />

### Validation

Use `accept`, `maxFiles`, `maxFileSize`, and `minFileSize` to validate files and handle rejected items with `onFileReject$`.

<Demo id="file-upload/validation" collapsed />

### Disabled

`disabled` on `FileUpload.Root` disables the dropzone, trigger, hidden input, and delete buttons.

<Demo id="file-upload/disabled" collapsed />

### With Field

Inside a `Field.Root`, use `Field.Label` and `Field.Description`. The Field provides the IDs, description, and `disabled` / `required` / `invalid` states.

<Demo id="file-upload/with-field" collapsed />

### With Form

`FileUpload.HiddenInput` keeps the native `<input type="file">.files` synchronized via `DataTransfer` so `new FormData(form)` receives accepted files and `<button type="reset">` clears them.

## Accessibility

- **Native elements**: Uses `<label for>`, `<button type="button">` for triggers and delete buttons, and a visually hidden `<input type="file">` (`tabIndex={-1}`, `aria-hidden="true"`).
- **Screen reader announcements**: Announces file additions, removals, and rejections via a polite live region.
- **Accessible labels**: `FileUpload.ItemDeleteTrigger` defaults `aria-label` to `"Remove <filename>"` when no `aria-label` is provided.

| Key | Element | Action |
| --- | --- | --- |
| `Enter` / `Space` | `FileUpload.Trigger` | Opens the native file picker. |
| `Enter` / `Space` | `FileUpload.ItemDeleteTrigger` | Removes the corresponding file item. |

# Components

All components in leve-ui. Each one is included in `@leve-ui/core` and is also published as its own package, `@leve-ui/<name>`.

You can also try every component in [Storybook](https://leve-ui-storybook.pages.dev).

| Component | Description |
| --- | --- |
| [Accordion](/components/accordion/) | A stack of headings that each show or hide a section of content. |
| [Alert](/components/alert/) | A message that draws attention without interrupting the user. |
| [Avatar](/components/avatar/) | An image that represents a user, with a fallback. |
| [Breadcrumb](/components/breadcrumb/) | The path to the current page in the site hierarchy. |
| [Checkbox](/components/checkbox/) | A control that is checked, unchecked, or mixed. |
| [Collapsible](/components/collapsible/) | A button that shows or hides a section of content. |
| [Field](/components/field/) | Connects a label, description and error message to a form control. |
| [Fieldset](/components/fieldset/) | Groups related form controls under a legend. |
| [Label](/components/label/) | A label for a form control. |
| [Meter](/components/meter/) | A value within a known range, such as disk usage. |
| [Progress](/components/progress/) | The progress of a task, determinate or indeterminate. |
| [Radio Group](/components/radio-group/) | A set of options where only one can be selected. |
| [Separator](/components/separator/) | A line that separates content. |
| [Switch](/components/switch/) | A control that turns an option on or off. |
| [Tabs](/components/tabs/) | Layered panels of content, one shown at a time. |
| [Toggle](/components/toggle/) | A button that is pressed or not pressed. |
| [Toggle Group](/components/toggle-group/) | A set of toggle buttons, single or multiple selection. |

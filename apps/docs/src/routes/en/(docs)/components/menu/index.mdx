# Menu

A list of actions that opens from a button.

Menu follows the [Menu Button WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/).

<Demo id="menu/default" />

## Installation

Install the all-in-one package:

```sh
pnpm add @leve-ui/core
```

Or only this component:

```sh
pnpm add @leve-ui/menu
```

## Anatomy

```tsx
import { Menu } from '@leve-ui/menu'; // or '@leve-ui/core'

<Menu.Root>
  <Menu.Trigger />
  <Menu.Content>
    <Menu.Item />
    <Menu.Separator />
    <Menu.Group>
      <Menu.GroupLabel />
      <Menu.Item />
    </Menu.Group>
    <Menu.CheckboxItem>
      <Menu.ItemIndicator />
    </Menu.CheckboxItem>
    <Menu.RadioGroup>
      <Menu.RadioItem>
        <Menu.ItemIndicator />
      </Menu.RadioItem>
    </Menu.RadioGroup>
    <Menu.Sub>
      <Menu.SubTrigger />
      <Menu.SubContent>
        <Menu.Item />
      </Menu.SubContent>
    </Menu.Sub>
    <Menu.Arrow />
  </Menu.Content>
</Menu.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `Menu.Root` | `<div>` | Wraps the parts and holds the open state. |
| `Menu.Trigger` | `<button>` | The button that opens the menu. |
| `Menu.Content` | `<div>` | The menu, a `popover="manual"` element in the top layer. |
| `Menu.Item` | `<div>` | An action. |
| `Menu.Group` | `<div>` | A group of items, named by its GroupLabel. |
| `Menu.GroupLabel` | `<div>` | The name of a group. Not an item. |
| `Menu.CheckboxItem` | `<div>` | An item that is turned on or off. |
| `Menu.RadioGroup` | `<div>` | A set of RadioItems where one is selected. |
| `Menu.RadioItem` | `<div>` | An item of a RadioGroup. |
| `Menu.ItemIndicator` | `<span>` | The check mark of a CheckboxItem or RadioItem, hidden while unchecked. |
| `Menu.Sub` | `<div>` | Wraps a submenu and holds its open state. |
| `Menu.SubTrigger` | `<div>` | The item that opens a submenu. |
| `Menu.SubContent` | `<div>` | The submenu, placed next to its SubTrigger. |
| `Menu.Separator` | `<div>` | A line between items. |
| `Menu.Arrow` | `<div>` | Optional. An arrow pointing at the Trigger, drawn with CSS. |

Items cannot be links yet: rendering an item as `<a>` or Qwik City's `<Link>` is planned with `asChild` ([#153](https://github.com/leve-ui/leve-ui/issues/153)).

## Examples

### Checkbox and Radio Items

`Menu.CheckboxItem` turns an option on or off, and `Menu.RadioItem` selects one value of a `Menu.RadioGroup`. Both take `bind:` signals like the other controls. Space changes them without closing the menu; a click or Enter changes them and closes it.

<Demo id="menu/checkable" collapsed />

### Submenu

`Menu.Sub` nests a menu. ArrowRight, Enter or Space on the `Menu.SubTrigger` opens it and focuses its first item; ArrowLeft and Escape close only the submenu. Hovering the SubTrigger opens it and keeps focus on the SubTrigger. Selecting an item in the submenu closes the whole menu.

<Demo id="menu/submenu" collapsed />

### Context Menu

`Menu.ContextTrigger` opens the menu at the pointer on right click, `Shift + F10` or long press, instead of from a button. See [Context Menu](/components/context-menu/).

## Accessibility

Complies with the [Menu Button WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/).

- `Menu.Trigger` renders `aria-haspopup="menu"`, `aria-expanded` and `aria-controls`. `Menu.Content` renders `role="menu"` and is named by the Trigger with `aria-labelledby`.
- Items render `role="menuitem"` and `tabindex="-1"`: focus moves between them with the keyboard (roving focus), and the menu is one tab stop.
- Disabled items render `aria-disabled="true"`. They are announced but cannot be selected, and arrow keys skip them.
- `Menu.Group` renders `role="group"`, named by its `Menu.GroupLabel`.
- `Menu.SubTrigger` renders `role="menuitem"` with `aria-haspopup="menu"`, `aria-expanded` and `aria-controls`; `Menu.SubContent` renders `role="menu"`, named by its SubTrigger.
- `Menu.CheckboxItem` and `Menu.RadioItem` render `role="menuitemcheckbox"` / `role="menuitemradio"` with `aria-checked`. `Menu.RadioGroup` renders `role="group"`; name it with `aria-label`, or place it in a `Menu.Group` with a label. `Menu.ItemIndicator` is hidden from assistive technologies, since `aria-checked` conveys the state.

### Keyboard Interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` / `ArrowDown` | On the Trigger, opens the menu and focuses the first item. |
| `ArrowUp` | On the Trigger, opens the menu and focuses the last item. |
| `ArrowDown` / `ArrowUp` | Moves focus to the next / previous enabled item. Wraps around when `loop` is set. |
| `Home` / `End` | Moves focus to the first / last enabled item. |
| A character | Moves focus to the next item that starts with the typed characters. |
| `Enter` / `Space` | On an item, selects it and closes the menu. |
| `Space` | On a checkbox or radio item, changes it without closing the menu. |
| `Enter` | On a checkbox or radio item, changes it and closes the menu. |
| `ArrowRight` / `Enter` / `Space` | On a SubTrigger, opens the submenu and focuses its first item. |
| `ArrowLeft` | In a submenu, closes it and returns focus to its SubTrigger. |
| `Escape` | Closes the submenu, or the menu, and returns focus to the SubTrigger or the Trigger. |
| `Tab` | Closes the menu and moves focus on. |

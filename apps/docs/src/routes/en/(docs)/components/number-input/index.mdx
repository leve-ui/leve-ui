# Number Input

Numeric text field with increment/decrement triggers and locale-aware formatting.

Number Input implements the [WAI-ARIA APG Spinbutton pattern](https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/), providing keyboard stepping, `Intl.NumberFormat` formatting and parsing, clamping, and form reset support.

<Demo id="number-input/default" />

## Installation

Install the individual package, or use `@leve-ui/core` to get every component at once:

<Install package="@leve-ui/number-input" />

## Anatomy

```tsx
import { NumberInput } from '@leve-ui/number-input'; // or '@leve-ui/core'

<NumberInput.Root>
  <NumberInput.DecrementTrigger>-</NumberInput.DecrementTrigger>
  <NumberInput.Input />
  <NumberInput.IncrementTrigger>+</NumberInput.IncrementTrigger>
</NumberInput.Root>
```

| Part | Element | Description |
| --- | --- | --- |
| `NumberInput.Root` | `<div>` | Wraps the parts, manages the numeric state, and provides context. |
| `NumberInput.Input` | `<input>` | Spinbutton text input (`role="spinbutton"`, `inputMode="decimal"`). |
| `NumberInput.IncrementTrigger` | `<button>` | Button (`tabIndex={-1}`) that increments the value by `step`. |
| `NumberInput.DecrementTrigger` | `<button>` | Button (`tabIndex={-1}`) that decrements the value by `step`. |

## API Reference

### Root

<PropsTable component="number-input" part="Root" />

| Data attribute | Value |
| --- | --- |
| `data-leve-number-input` | Always present |
| `data-state` | `"empty"` \| `"filled"` |
| `data-disabled` | Present when disabled |
| `data-readonly` | Present when read-only |
| `data-invalid` | Present when invalid |

The numeric value is uncontrolled with `defaultValue`, or controlled with `bind:value`. `onValueChange$` is called when the committed value changes.

Inside a Field, the input ID comes from the Field and `ids` is ignored ([ADR 0024](https://github.com/leve-ui/leve-ui/blob/main/adr/0024-wire-field-ids-and-descriptions-from-the-field-root.md)).

## Accessibility

Follows the [WAI-ARIA APG Spinbutton pattern](https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/).

- Provide an accessible name for `NumberInput.Input` via `Field.Label`, `aria-label`, or `aria-labelledby`.
- `NumberInput.Input` sets `role="spinbutton"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and `aria-valuetext` (when the formatted text differs from the plain number string).
- `IncrementTrigger` and `DecrementTrigger` are excluded from the tab order (`tabIndex={-1}`) and prevent `mousedown` default so clicking them keeps focus on the input. They default `aria-label` to `"Increment"` and `"Decrement"`.

### Keyboard Interactions

| Key | Description |
| --- | --- |
| `ArrowUp` | Increments the value by `step`. |
| `ArrowDown` | Decrements the value by `step`. |
| `PageUp` | Increments the value by `largeStep`. |
| `PageDown` | Decrements the value by `largeStep`. |
| `Home` | Sets the value to `min` (when `min` is defined). |
| `End` | Sets the value to `max` (when `max` is defined). |
| `Enter` | Parses, clamps (if `clampValueOnBlur` is true), commits, and formats the input value. |

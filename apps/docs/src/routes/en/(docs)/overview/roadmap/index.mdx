# Roadmap

The components and features planned for leve-ui.

Components are built in milestones, in order of the shared logic they depend on. Progress is tracked in [GitHub milestones](https://github.com/leve-ui/leve-ui/milestones). There are no release dates.

## Milestones

### [M0: Foundation](https://github.com/leve-ui/leve-ui/milestone/1)

Shared logic used by the components, such as ids, focus management, keyboard interaction and controlled state, and the library-wide design decisions.

### [M1: Standalone](https://github.com/leve-ui/leve-ui/milestone/2)

Components that are not displayed on top of other content. Released: Accordion, Alert, Avatar, Breadcrumb, Checkbox, Collapsible, Field, Fieldset, Label, Meter, Progress, Radio Group, Separator, Switch, Tabs, Toggle and Toggle Group.

Planned: Toolbar.

### [M2: Overlay](https://github.com/leve-ui/leve-ui/milestone/3)

Components displayed on top of other content: Dialog, Drawer, Popover, Tooltip, Hover Card, Menu, Context Menu, Toast and Combobox.

### [M3: Inputs](https://github.com/leve-ui/leve-ui/milestone/4)

Input components: Number Input, Password Input, Pin Input, Slider, Rating Group, Clipboard, File Upload and Pagination.

### [M4: Collections](https://github.com/leve-ui/leve-ui/milestone/5)

Components for choosing from a list: Listbox, Select, Tree View and Steps.

### [M5: Advanced](https://github.com/leve-ui/leve-ui/milestone/6)

Larger components: Date Input, Date Picker and Tour.

## Qwik v2

leve-ui supports Qwik 1.x. Support for Qwik v2 (`@qwik.dev/core`) is tracked separately in the [Qwik v2 milestone](https://github.com/leve-ui/leve-ui/milestone/7).

## Tooling for AI agents

An MCP server and agent skills, to help coding agents use leve-ui, are planned.

## API stability

leve-ui is in the 0.x series. Until 1.0, breaking changes are released as minor versions (0.1 → 0.2) and are listed in the changelogs. Before 1.0, beta versions will be published under the `beta` npm tag.

## Request a component

Is a component missing? Search the [issues](https://github.com/leve-ui/leve-ui/issues) and open a new one if it is not there.
